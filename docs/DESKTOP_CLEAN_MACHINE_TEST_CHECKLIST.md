# Windows 桌面版安装检查清单

此清单用于检查由当前源码构建的 NSIS 安装包。每次发布时记录安装包版本、SHA-256、Windows 版本和实际结果；本文件本身不代表任何候选包已通过测试。

## 安装前

- [ ] Windows 10/11 干净测试环境
- [ ] 记录安装包文件名、版本与 SHA-256
- [ ] 确认本机 `13000`、`18000` 端口未被占用
- [ ] 确认测试不使用开发机现有数据库

## 安装与启动

- [ ] 安装程序完成并创建快捷方式
- [ ] 程序资源目录包含 backend、frontend 和 runtime
- [ ] 应用在一分钟内打开且无错误弹窗
- [ ] 前端 `http://127.0.0.1:13000` 可访问
- [ ] 后端 `http://127.0.0.1:18000/health` 返回成功
- [ ] SQLite 数据库和日志写入 `C:\ProgramData\FlyArrangement`

## 首次使用

- [ ] 没有预置的通用用户名或密码
- [ ] 按 [README](../README.md) 中的 `create_admin.py` 命令创建管理员
- [ ] 新管理员可登录并创建、读取和修改一条测试记录
- [ ] 重启应用后管理员和测试记录仍存在

## 退出与卸载

- [ ] 关闭应用后 `13000` 与 `18000` 端口释放
- [ ] 卸载程序正常完成
- [ ] 卸载后 `C:\ProgramData\FlyArrangement` 用户数据仍保留
- [ ] 记录实际问题、日志路径和复现步骤
