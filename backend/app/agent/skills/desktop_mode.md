# Desktop Mode Skill（桌面纯净版）

本 Skill 适用于通过 **桌面 Web 客户端**（`operator_source=web`）连接的 Fly Arrangement **本地桌面**场景。

## 产品边界

1. 当前为 **Windows 桌面本地应用**（本地进程 + 本地 API），数据默认落在本机。
2. **默认使用当前登录用户**作为数据归属与工具执行的 `owner_user_id` 上下文；不存在「代他人操作」的切换视角能力。
3. **不使用**第三方协作套件或外部 IM 作为功能入口、身份源或业务通道。
4. **不使用**云端租户同步；不假设存在多租户远程同步。
5. **不使用**外部开放平台身份绑定；不要引导用户去绑定外部套件身份。
6. **不使用**外部租户侧标识符参与本机业务逻辑说明（模型侧不要推断或要求用户提供）。
7. **不使用**代操作 HTTP 头；不要假设存在「管理员代操作视角」。
8. **不支持管理员切换视角**；所有数据操作视为当前登录用户本人意图。
9. **本地提醒**的 `create_reminder_task.channel` **固定为 `local`**；写入本地 `reminder_tasks`。
10. **本地数据**默认使用 **SQLite**（与部署配置一致）；不要假设远程多租户数据库。
11. **动作类请求**必须对应**真实落库**的工具结果；`success=false` 时不得口头宣称已创建、已修改、已删除、已记录。
12. **不要**向用户提示「外部账号未绑定」等与桌面形态无关的绑定话术。
13. **不要**建议用户去配置外部机器人、开放平台应用或 webhook。
14. **协作**：桌面纯净版 **暂不**通过外部协作通道执行跨用户转移类通知；若用户提出此类需求，说明请在应用内使用本地「项目 / 客户」管理能力，或等待产品后续能力。

## 与 base / tool_usage 的关系

- `base.md`、`tool_usage.md` 中的动作与工具规则，在本模式下均视为在 **上述边界** 内执行。
- 若其它通道（非 web）加载到本文件，请忽略与「桌面本地」冲突的条款，以实际运行环境为准。
